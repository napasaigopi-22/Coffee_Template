About us

A small cafe system built from your Python project.

Python Cafe began as a command-line ordering program. Now it has a browser menu, customer order flow, receipts, and saved order history using SQLite.

Today's focus Simple ordering, clean records, and easy learning.

What customers can do

Select coffee or bakery items, submit an order, and get a receipt immediately.

What the database stores

Customer name, order total, item count, order date, and each ordered item.

What you can improve next

Add quantities, login, admin controls, item images, or online deployment.
